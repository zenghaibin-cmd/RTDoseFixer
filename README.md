# RTDoseFixer

将 CyberKnife（Accuray，Sunnyvale，CA）的 RT Dose 转换为 Varian Eclipse 可用格式的工具。

## 功能

- 读取 CyberKnife 导出的 RT Dose 文件
- 转换为 Varian Eclipse 兼容格式
